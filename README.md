# ✈️ Vacation Planning Website

Vacation Planning Website is a travel planning platform that helps users discover the most suitable vacation packages based on their destination, travel dates, number of travelers, and budget preferences.

The application combines real flight and hotel data to generate personalized travel recommendations, allowing users to compare options and plan their trips from a single interface.

🌐 Live Demo

https://vacationplanningwebsite.netlify.app/

## 🚀 Features

* Vacation destination planning
* Real-time flight recommendations
* Real-time hotel recommendations
* Cheap, Medium, and Comfort budget options
* Total vacation cost calculation
* Responsive and user-friendly design
* Smooth animations and modern interface

## 🛠️ Technologies

* React
* Vite
* Tailwind CSS
* Redux Toolkit
* React Router DOM
* Framer Motion
* Lucide React

## ⚙️ Installation

```bash
git clone https://github.com/haticenurt/vacation-planning-website.git

cd vacation-planning-website

npm install

npm run dev
```

The application will run at:

```txt
http://localhost:5173
```

## 🔌 Backend Integration

The frontend communicates with a Node.js and Express.js backend service that:

* Retrieves real flight data
* Retrieves real hotel data
* Creates vacation packages
* Calculates package costs
* Returns personalized travel recommendations

Backend Repository:

```txt
https://github.com/haticenurt/vacation-planning-website-backend
```

Live Backend:

```txt
https://vacation-planning-website-backend.onrender.com
```

## 🎯 Purpose

The purpose of this project is to simplify the vacation planning process by bringing flight options, hotel options, and package recommendations together in a single platform, helping users make faster and more informed travel decisions.
